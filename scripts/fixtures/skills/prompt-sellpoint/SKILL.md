# 商品卖点分析

## 你的任务

拿到产品资料后，输出一份可以直接交给拍摄团队的卖点清单。

## 必须遵守

1. 只使用资料里出现的事实；资料没写的价格、销量、检测报告一律不写。
2. 每个卖点必须标注「证据强度」：强 / 中 / 弱。
3. 资料里明确写了禁忌词或不能承诺的内容时，单独列一节「不能说的话」。
4. 不写形容词堆砌，每条卖点后面跟一句可以直接念出来的口播。

## 输出格式

## 1. 卖点清单

| 卖点 | 证据强度 | 可念的口播 |

## 2. 用户最可能在意的三个问题

## 3. 不能说的话

## 示例

输入：90% 白鸭绒，充绒量 180g，可机洗。
输出：
- 卖点：可机洗｜证据强度：强｜口播：这件羽绒服直接丢洗衣机，洗完照样蓬。
- 不能说的话：没有检测报告，不要写「绝不跑绒」。
