# 电商工作台 · 网页版使用手册

## 本地启动

安装 Node.js 22，在项目目录执行 `npm ci`，然后执行 `npm run dev -- --hostname 127.0.0.1 --port 3010`。打开 http://localhost:3010 ，首次设置管理员后进入工作台。

## 快速配置 API

进入「设置 → 用你自己的 API，快速开始」，填写 API 地址、Key、模型名称，保存即可供文字功能共用；看图、生图、语音按需添加。步骤与兼容范围见 [API 配置指南](API_SETUP.md)。原有连接及内容备份功能位于页面底部折叠区。管理后台页面与导航入口已移除。

## 可选：这台电脑每次直接进入工作区

先创建自己的管理员。然后在本机 `.env.local` 添加 `DIRECTOR_LOCAL_ACCESS_USERNAME=你的管理员用户名`，重启上述绑定 127.0.0.1 的服务。之后无需输入密码，继续使用这个管理员的历史内容；旧 `/login`、`/setup` 和 `/admin` 地址返回工作台。用户名只是示例占位，需换成自己真实创建的账号，不要提交 `.env.local`。

仅允许 localhost、127.0.0.1 或 ::1 的本机 Host 与同源请求，所选账号必须存在、启用且为管理员。不设置此变量时保留普通网页登录；桌面模式保持原行为。不要把本机免登录服务通过代理或隧道公开，也不要用 `DIRECTOR_WEB_AUTH_DISABLED=1` 替代它，否则会进入桌面数据作用域，无法读取原网页账号的历史。

历史及 API 私有配置保存在 `.director-platform-data/`，不要删除、上传或随公开源码分发。正常内容备份不包含服务商 Key；若自己备份整个运行目录，应作为私密备份保管。
