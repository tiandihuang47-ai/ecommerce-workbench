# 电商工作台 · 网页版使用手册

## 本地启动：直接使用，无需用户名和密码

安装 Node.js 22.12.0 或更高版本，在项目目录执行 `npm ci`，然后执行 `npm run dev -- --port 3010`。打开 http://localhost:3010 即可进入工作台，无需先注册或创建管理员。默认启动命令只监听 127.0.0.1，不对局域网开放。关闭服务后，该地址不能继续访问。

新工作区使用固定的本机存储归属，不创建登录账号、默认密码或公共凭据；刷新、重启后继续读取同一份内容。旧 `/login`、`/setup` 和 `/admin` 地址返回工作台。管理后台页面与导航入口已移除。

## 快速配置 API

进入「设置 → 用你自己的 API，快速开始」，填写 API 地址、Key、模型名称，保存即可供文字功能共用；看图、生图、语音按需添加。步骤与兼容范围见 [API 配置指南](API_SETUP.md)。原有连接及内容备份功能位于页面底部折叠区。

## 原有内容与多个已有账号

已有账号时，默认进入用户列表中第一个启用的管理员工作区，保持其原有数据归属，不新建账号、不改密码。需要明确选择另一个已有管理员时，在私有 `.env.local` 设置 `DIRECTOR_LOCAL_ACCESS_USERNAME=自己的管理员用户名` 并重启；填写的账号必须存在、启用且为管理员，错误配置不会自动换到别人的工作区。已有账号全部停用或只有普通成员时，不会自动提升权限。

## 可选：启用账号登录

仅在需要原有账号登录方式时，在私有 `.env.local` 设置 `DIRECTOR_REQUIRE_LOGIN=1` 并重启。这会关闭本机自动进入；新实例按页面提示创建管理员，已有实例使用原有账号。该设置优先于 `DIRECTOR_LOCAL_ACCESS_USERNAME`。

纯本机工作区与登录账号的数据归属不同：后续切换登录方式不会自动迁移本机内容，应先通过内容备份功能保存资料，再在目标工作区按支持的范围导入。不要用 `DIRECTOR_WEB_AUTH_DISABLED=1` 代替本机模式，否则会进入桌面数据作用域。

## 访问与私有数据

默认直接访问仅适用于自己控制的本机环境；请求主机必须是 localhost、127.0.0.1 或 ::1，同源检查仍然保留。共享、公网、反向代理或隧道部署必须先设置 `DIRECTOR_REQUIRE_LOGIN=1`，再单独配置 HTTPS、访问控制及网络绑定，不能把免登录服务公开。

历史及 API 私有配置保存在 `.director-platform-data/`，不要删除、上传或随公开源码分发。正常内容备份不包含服务商 Key；若自己备份整个运行目录，应作为私密备份保管。Electron 桌面模式保持原行为。
