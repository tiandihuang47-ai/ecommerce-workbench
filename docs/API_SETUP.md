# 电商工作台：用自己的 API 快速开始

## 只想写文案：先填三个内容

1. 启动项目，打开「设置 → 用你自己的 API，快速开始」。
2. 选择服务商，或保留「自定义 / 中转 API」。从服务商后台复制 **API 地址（Base URL）**、**API Key** 和 **模型名称**。
3. 用途选择「文字」，保留「设为默认文字模型」，点击「保存并启用」。保存不调用模型，不产生模型费用，立即生效。
4. 可以直接去 AI 对话、脚本、选题、复刻文案或复盘使用。也可以点「验证此模型」先检查一次真实调用；验证会先提示可能产生费用。

不需要准备作者使用的全部模型，也不用逐个功能填 Key。文字模型应支持稳定返回 JSON；AI 对话中的 Skill 运行还需要模型支持工具调用。验证成功只表示这次对应能力请求成功，不能保证所有业务任务的输出质量。

「获取模型列表」从你填写的 API 读取可用名称，不推断模型能力。有些中转站没有这个接口，手动填模型名称即可。模型名称须与服务商提供的一致，通常不能填写产品的中文昵称。

API 地址使用服务商提供的 Base URL，不填网页后台地址或完整的 `/chat/completions` 地址，不在地址里放 Key。默认采用 OpenAI 兼容格式；使用 Anthropic Messages 时，展开「连接名称与接口格式」切换为 Anthropic。其他未适配协议不能仅靠更换地址接入。

## 需要哪些能力，再加哪些

| 需求 | 用途选择 | 要求 |
| --- | --- | --- |
| 文案、脚本、选题、对话 | 文字 | OpenAI Chat Completions 或 Anthropic Messages |
| 产品图片、视频画面分析 | 看图 | 接受图片输入的 OpenAI 兼容接口 |
| 上传音频转文字 | 语音转写 | 按服务商说明选音频对话或音频转写接口 |
| 生成图片 | 生图 | OpenAI Images 或火山 Seedream 格式 |

同一服务商的多个模型可选择已经保存的「API 连接」，Key 留空会复用，不必重复填写。然后换用途、填对应模型名称并保存。文字模型不会自动获得看图、生图或转写能力。未配能力仍可手动输入逐字稿、整理素材等；需要该能力的 AI 请求会提示缺少配置。

语音验证需要自行选择一段 1MB 以内、有人声的 MP3/WAV。生图验证会生成测试图，因此可能比文字验证贵。图片生成成功也不等于支持参考图编辑；需要参考图的任务仍取决于服务商具体支持。

## 保留自己习惯的多个模型

已有配置不会自动替换。只有主动保存为默认，才会更改对应能力的功能分配；文字默认包含复刻文案。看图、生图、语音不会随文字默认一起修改。

展开「高级：多个模型组合与逐功能分配」，可以让脚本用一个模型、对话用另一个。选择「跟随默认 / 原有配置」可清除某个功能的覆盖。再次在上方勾选并保存统一默认，会清除该能力的逐功能覆盖。

点「恢复原有模型组合」可回到项目原配置，新增连接和历史内容保留。已有生图任务保留原来的模型选择；新建任务采用新增的默认生图模型。如果只是添加备用模型，可取消「设为默认」再保存，并在高级配置中分配。

修改共用连接的 Key、地址或接口格式会影响共用该连接的所有模型，已有验证状态会失效。遇到「配置已变化」请刷新页面后重试，避免不同窗口互相覆盖。

## 密钥与公开源码

Key 存在服务端私有运行目录 `.director-platform-data/model-router/`，页面只显示是否保存，不读取明文；不写进源码 YAML、不放进浏览器 localStorage，也不随内容导出。Git 已忽略运行目录，但不要手动强制上传它，也不要把自己的 `.env.local`、日志或整个本机项目压缩包当成公开版发布。

网页连接属于当前服务实例的全局配置；默认在自己电脑上直接进入本机工作区，无需创建用户名或密码。启用账号登录时由管理员管理。本机免登录模式只用于绑定 127.0.0.1 的本机访问；每个下载项目的人在自己的电脑上保存自己的 Key，不能共用作者的本机运行目录。服务端私有文件不是加密保险箱，仍应避免分享电脑账号或运行目录。

源码开发者仍通过中央模型路由增加业务 Route。设置保存的是私有 YAML 版本；不要直接在业务代码写模型名或 Key。底部「原有连接与数据管理」供兼容旧配置和内容备份使用，新增用户优先用顶部统一入口。
