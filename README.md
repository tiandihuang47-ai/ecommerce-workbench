# 电商工作台

电商工作台是一款免费开源的 AI 内容创作工具，适合电商商家、短视频创作者和小团队。如果你经常不知道拍什么、写稿费时间、产品资料和参考视频到处放，它可以帮你把这些工作集中起来，减少重复劳动。

你可以整理商品卖点，让 AI 帮你想选题、写口播稿，再按自己的要求修改；也可以拆解参考视频、提取视频里的讲话内容、生成商品场景图。做过的脚本、图片和复盘记录可以保存下来，下次继续使用，不必每次从零开始。

刚开始不用配置一大堆模型，接入一个自己的文字 AI 服务，就能先用对话和写稿功能，看图、生图、语音按需添加。项目可以在自己的电脑上运行，代码免费，AI 调用费用由服务商收取。你负责核对商品信息、决定最终内容，它帮你减少整理和起稿的时间，把精力留给产品、拍摄和客户。

## 本地启动

安装 Node.js 22.12.0 或更高版本，执行 `npm ci`，然后执行 `npm run dev -- --hostname 127.0.0.1 --port 3010`，访问 http://localhost:3010 。默认在自己电脑上直接进入工作台，无需创建用户名或密码；旧 `/login`、`/setup` 地址会返回首页。API 可以在设置页填写；需要环境变量时，把 `.env.example` 复制成 `.env.local`，只在本机填写。

新工作区使用本机内容目录；已有账号时继续使用用户列表中第一个启用的管理员工作区，也可以通过 `DIRECTOR_LOCAL_ACCESS_USERNAME` 指定已有管理员。需要账号登录时，在 `.env.local` 设置 `DIRECTOR_REQUIRE_LOGIN=1` 后重启；共享或公开部署须使用登录保护，详见 [网页版手册](docs/WEB_GUIDE.md)。

模型注册在 `config/models.yaml`，功能路由在 `config/model-routing.yaml`。模型访问权限、付费及第三方连接由使用者自行配置；没有密钥的能力不可用。

## 使用自己的 API

打开「设置 → 用你自己的 API，快速开始」，填写 **API 地址、API Key、模型名称**，点击「保存并启用」。一个文字模型可供对话、脚本、选题、复刻文案和复盘等文字功能共用，无需准备作者使用的全部模型。保存后立即生效，无需重启。

看图、生图、语音按需添加，同一连接可以复用 Key；多个模型组合可在高级配置中逐功能分配。已有配置不会自动替换。详见 [API 配置指南](docs/API_SETUP.md)；本机直接访问说明见 [网页版手册](docs/WEB_GUIDE.md)。

保存不会调用模型；「验证此模型」会先提示可能产生费用。兼容接口不代表支持全部能力，文字 JSON、工具调用、看图和参考图编辑取决于具体模型。

## 数据和安全

不要上传 `.env.local`、Cookie、账号数据库、聊天记录、产品资料、日志、截图、构建产物或已安装 App。不要将服务商密钥放进 `NEXT_PUBLIC_` 环境变量。开源源码不等于开放自己的在线服务，不要直接暴露开发服务器到公网。

此副本不含原 Git 历史、本地运行数据及内部项目记录。公开前必须重新扫描最终提交。不要使用旧迁移压缩包发布；本副本移除了该打包命令。

## 外部依赖和许可证

本版本执行源码泄密检查、独立依赖安装、类型检查、模型路由测试和生产构建。统一 API 配置另经 17 项隔离 HTTP 集成测试，覆盖文字、看图、语音、生图、持久化、权限与密钥脱敏；没有使用真实付费模型，尚未完成供应商端到端调用、桌面打包及全部业务流程验收。
